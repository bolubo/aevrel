# Maintainers

## Current maintainer

- **[@bolubo](https://github.com/bolubo)** — project lead, control-plane
  contracts, Kubernetes/Python boundaries, security response, releases.

## Responsibilities

Maintainers are expected to:

- review changes for correctness, safety, and scope;
- protect the source-read-only and fail-closed guarantees;
- keep public contracts and release artifacts consistent;
- triage issues and respond to security reports;
- mentor contributors and delegate review where appropriate.

The maintainer roster is intentionally small until there is a sustained
contributor base. Promotion and emeritus rules are in
[GOVERNANCE.md](GOVERNANCE.md).
